# Remix of Duo Midia & Studio

Crie o protótipo visual de uma plataforma web responsiva chamada DuoHub, pertencente à agência DuoMídia.

O DuoHub será uma central visual de serviços de marketing e comunicação para clientes da agência.

O objetivo principal é permitir que o cliente descubra tudo o que a DuoMídia oferece, escolha visualmente um serviço e envie uma solicitação de forma rápida, sem precisar conhecer termos técnicos.

A experiência deve ser simples, visual, acolhedora, profissional e intuitiva. Não deve parecer um sistema de chamados tradicional.

Por enquanto, crie somente a interface visual, sem banco de dados, sem autenticação e sem integrações externas.

A página inicial deve conter:

1. Uma saudação ao cliente:

“Olá, seja bem-vindo ao DuoHub.”

2. Um texto curto:

“Encontre uma solução, veja exemplos e envie sua solicitação em poucos passos.”

3. Um campo de busca:

“Do que você precisa?”

4. Uma seção chamada “Serviços mais solicitados”, com cartões visuais para:

- Post para redes sociais

- Story

- Carrossel

- Reel

- Banner

- Assinatura de e-mail

- Crachá

- Figurinha para WhatsApp

5. Uma seção de categorias:

- Redes Sociais

- Design e Materiais

- Audiovisual

- Campanhas

- Comunicação

- Sites e Digital

- Coberturas

- Outros

6. Cada serviço deve aparecer em um cartão visual contendo:

- imagem ou ilustração representativa;

- nome do serviço;

- descrição curta em linguagem simples;

- botão “Ver exemplo”;

- botão “Solicitar”;

- informação se está incluído no plano ou se utiliza créditos.

7. Inclua um cartão em destaque:

“Não encontrou o que precisa?”

Botão: “Conte para a gente”.

8. A navegação deve possuir:

- Início

- Nova solicitação

- Minhas solicitações

- Meus serviços

- Créditos

- Arquivos

- Ajuda

9. O layout deve funcionar bem no computador e principalmente no celular.

10. Não use termos técnicos como briefing, dimensão, formato gráfico ou mídia programática na área do cliente.

11. Use textos em português do Brasil.

12. Crie dados fictícios para demonstrar a interface.

Use uma identidade contemporânea, elegante e próxima, compatível com uma agência de publicidade experiente.
